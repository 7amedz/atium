# Atium

> _"Atium lets you see, marginally, into the future."_
> — Kelsier, _Mistborn_ (Brandon Sanderson)

Atium is a in progress dual-curve bootstrapping and swap valuation engine for EUR markets.

The goal is to learn the finance/mathematics behind such an engine all the while practicing modern C++(23).

So far it only includes a few implemented and tested mathematical building blocks.

### Build

```sh
cmake --preset debug
cmake --build --preset debug
ctest --preset debug

```
